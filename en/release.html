How to release a track

From file to Spotify and Apple Music — step by step, no label.

Prepare the file in the bot →

Step 1. Prepare the file

  • MP3 320 or WAV with correct tags.
  • Cover 3000×3000.
  • Description and genre.

Step 2. Pick a distributor

  • Free: Amuse, Loudly.
  • Paid: DistroKid, TuneCore.

Step 3. Upload

  • Create a release and upload the track.
  • Fill in the metadata.
  • Set the release date (+2 weeks minimum).

FAQ

How do I release a track on streaming?

Prepare a tagged file and cover, upload via a distributor, wait for moderation.

What is ISRC?

A unique track code issued by the distributor.

How long does publishing take?

Usually 1–2 weeks; set the release date in advance.
