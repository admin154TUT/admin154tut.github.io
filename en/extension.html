Suno Chrome extension — download to Telegram in one click

Adds a “Download to Telegram” button right on the Suno track page. One click — the file goes to the bot.

Install extension →

How it works

  1. Install from the Chrome Web Store.
  2. Open a track on suno.com.
  3. Click “Download to Telegram” in the bottom-right corner.
  4. The bot @sunoMP3bot sends the MP3 with cover and tags.

What you can get

  • MP3 320 with cover, title and artist tags.
  • WAV without compression.
  • Lyrics.
  • Vertical video 1080×1920 for Reels and Shorts.
  • Prompt + lyrics as a TXT.
  • Tag editor and batch ZIP.

FAQ

Is the extension free?

Yes. The bot has a free daily limit and a PRO plan.

Does it work on mobile?

No — Chrome extensions work on desktop Chrome only. On mobile, just send the link to the bot.
