PNG в PDF — конвертер онлайн бесплатно

Конвертируй PNG в PDF за секунду. Без установки программ, без регистрации — прямо в Telegram.

Скриншоты и картинки удобно собирать в PDF, когда нужно передать инструкцию, отчёт или подборку изображений одним файлом. PDF открывается на любом устройстве одинаково и не зависит от того, какие программы установлены у получателя.

Каждое изображение становится страницей A4 с полями — текст на скриншоте остаётся читаемым при 150 dpi. Несколько картинок собираются в документ в том порядке, в котором вы их отправили.

Этот формат браузер сам не сделает — нужен сервер. Пришли файл боту, он справится за секунду.

Когда это нужно

  • Скриншоты нужно отправить одним документом
  • Собираете инструкцию или отчёт из картинок
  • Нужен формат для печати без потери вёрстки

Как конвертировать

  1. Открой бота @format_box_bot в Telegram
  2. Пришли файл
  3. Выбери «PDF» — получишь готовый файл

Что важно знать

  • PDF фиксирует страницы — вёрстка сохранится везде
  • Скриншоты лучше смотрятся на странице A4 с полями
  • Разрешение 150 dpi хватает для читаемости текста

Частые ошибки

  • Отправлять 20 скриншотов отдельными файлами — получатель запутается
  • Собирать PNG в PDF без сжатия — файл раздуется

Скорость, приватность и лимиты

Конвертация занимает 1–3 секунды на файл. Файл не хранится: он удаляется с сервера сразу после отправки результата, поэтому вернуться к нему позже нельзя — сохраните результат себе. Количество файлов не ограничено. Ограничение по размеру — 20 МБ, это лимит Telegram на передачу файлов боту.

Частые вопросы

Соберутся ли несколько картинок?

Да, альбомом — в один PDF по порядку.

Текст на скриншоте будет читаемым?

Да, при 150 dpi.

Можно ли потом разбить обратно?

Да, PDF → картинки (ZIP).
