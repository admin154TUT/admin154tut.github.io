# САЙТ: 6 ШАГОВ ДО ВНЕШНИХ ССЫЛОК

Готовые файлы: `index.html`, `sitemap.xml`, `robots.txt`.

Зачем: ссылки с VC, DTF и Habr — `nofollow`, они не передают вес. А ссылки
с твоего собственного сайта — обычные, `dofollow`. Одна такая страница
ускоряет индексацию всех 19 статей.

Хостинг бесплатный, домен не нужен: GitHub Pages даёт адрес
`https://твой-логин.github.io/suno-guides/`.

---

## Шаг 1. Аккаунт GitHub

[github.com](https://github.com) → Sign up. Нужна почта, всё бесплатно,
карта не требуется.

## Шаг 2. Новый репозиторий

Справа сверху «+» → **New repository**.

- **Repository name:** `suno-guides`
- **Public** (обязательно, иначе Pages не включится)
- галочку «Add a README file» можно поставить
- **Create repository**

## Шаг 3. Загрузить три файла

В репозитории: **Add file → Upload files**.

Перетащи из папки `suno-bot/site/`:

- `index.html`
- `sitemap.xml`
- `robots.txt`

Внизу **Commit changes**.

## Шаг 4. Включить Pages

**Settings** (вверху репозитория) → слева **Pages**.

- **Source:** Deploy from a branch
- **Branch:** `main`, папка `/ (root)`
- **Save**

## Шаг 5. Подождать минуту

Через 1–2 минуты страница оживёт по адресу:

```
https://ТВОЙ-ЛОГИН.github.io/suno-guides/
```

## Шаг 6. Прислать адрес мне

Я заменю `example.com` в `canonical`, `robots.txt` и `sitemap.xml` на реальный
адрес, и добавлю страницу в Яндекс.Вебмастер и Google Search Console — это
можно сделать уже с твоим адресом.

---

## Что это даст

| Что | Эффект |
|---|---|
| 19 исходящих ссылок на статьи | робот обойдёт их по ссылкам с индексируемого сайта |
| Один домен, который ты контролируешь | сюда можно ставить ссылки с VC, DTF, Habr — уже без nofollow |
| sitemap.xml | быстрая подача в вебмастера |
| Своя витрина | если статья на Telegra.ph умрёт, контент останется у тебя |

---

## После запуска — что сделать ещё

1. **Яндекс.Вебмастер** → добавить сайт → подтвердить → «Индексирование» →
   «Файлы Sitemap» → указать `sitemap.xml`.
2. **Google Search Console** → то же самое.
3. В описании каналов и в шапке профиля поставить ссылку **на сайт**, а не на
   бота. Сайт уже ведёт на бота с меткой `s_site`.

---

## Чего ждать

Индексация нового сайта — от нескольких дней до двух недель. Быстрее, если
сразу подать sitemap в оба вебмастера и поставить ссылку с сайта в описании
канала.

Это последний кусок, который нельзя сделать без тебя: нужен аккаунт.
Остальное — статьи, перелинковка, метки — уже сделано.
